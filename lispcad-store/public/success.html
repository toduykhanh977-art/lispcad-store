📥 Bấm Vào Đây Để Tải File Ngay

⚡ Hệ thống đã tự động mở tải file về máy bạn. Nếu chưa thấy tải, hãy bấm nút màu xanh ở trên!

💡 Hướng Dẫn Nạp Lisp Vào AutoCAD & Kích Hoạt (1 Phút):

  1. Bấm nút 📋 Copy Mã Đơn Hàng ở khung phía trên để lưu sẵn mã kích hoạt.
  2. Mở phần mềm AutoCAD, gõ lệnh APPLOAD (hoặc gõ tắt AP) rồi nhấn Enter.
  3. Chọn file Lisp vừa tải về và bấm Load.
  4. Khi AutoCAD hiện ô hỏi Mã đơn hàng, bạn dán (Ctrl + V) mã vừa copy vào rồi nhấn Enter để kích hoạt bản quyền 1 máy và sử dụng ngay.
  5. (Mẹo hay): Để Lisp tự động nạp mỗi lần mở AutoCAD, bấm nút Contents... ở mục Startup Suite (hình chiếc cặp) và thêm file Lisp vào.
